# Электронный журнал учёта работы педагога ДОП

> Репозиторий: [https://github.com/Romosol/Digital-LogBook-for-GBU-DO-RDOT](https://github.com/Romosol/Digital-LogBook-for-GBU-DO-RDOT)

Графическое приложение на **Python (Tkinter + openpyxl)** для автоматизированного заполнения и формирования полного печатного бланка классного журнала формата А4 под подшивку (42 листа в единой книге Excel).

---

## 📌 Вкладки и функционал программы

1. **Параметры обложки**: выбор учебного года, предпросмотр листа с отступом 30 мм слева под скоросшиватель.
2. **Титульный лист (стр. 1)**: наименование организации, учебный год, даты начала и окончания.
3. **Оборот титульного листа (стр. 2)**: Ф. И. О. педагога, правила ведения журнала (10 пунктов, отступ 30 мм справа под корешок).
4. **Основные данные (стр. 3)**: подразделение, кружок/секция, группа, староста, концертмейстер, расписание занятий на неделю и изменения.
5. **Учебные месяцы (Сентябрь — Август, стр. 4–27)**: 12 разворотов учёта занятий, посещаемости обучающихся и тем уроков.
6. **Массовые мероприятия (стр. 30–31)**: учёт массовой работы с детьми.
7. **Творческие достижения (стр. 32–33)**: конкурсы, выставки, награды.
8. **Список обучающихся (стр. 34–39)**: 3 разворота по 10 обучающихся с медицинскими заключениями и контактными данными.
9. **Инструктаж по технике безопасности (стр. 38–39)**: даты, содержание инструктажа и подписи.
10. **Годовой цифровой отчёт (стр. 40)**: распределение по полугодиям, годам обучения и требованиям по охране труда.
11. **Отработанное время**: сводный годовой табель часов педагогической нагрузки и концертмейстера.
12. **Формирование Excel**: экспорт отдельных листов или полного готового журнала (42 листа) со всеми формулами и стилями печати.

## 🚀 Быстрый запуск

### Вариант 1: Запуск готового EXE (Windows)
Скачайте готовый автономный файл `Journal_DOP.exe` со страницы [GitHub Releases](https://github.com/Romosol/Digital-LogBook-for-GBU-DO-RDOT/releases) и запустите его в один клик без установки Python.

### Вариант 2: Запуск из исходного кода
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите:
   - **Windows**: дважды кликните по `run.bat` или выполните `python app_gui.py`
   - **macOS / Linux**: выполните `./run.sh` или `python3 app_gui.py`

## 🔄 Контроль версий и автообновление

Приложение автоматически сверяет текущую версию с актуальным релизом на GitHub при каждом запуске. При выходе новой версии программа предложит в один клик перейти на страницу релиза и скачать обновлённый `.exe` файл.
