# Графический интерфейс для классного журнала (Python GUI)

Графическое приложение на **Python (Tkinter + ttk + openpyxl)** для формирования печатного бланка обложки и титульных страниц классного журнала формата А4 под подшивку.

---

## 📌 Вкладки и функционал
- **Вкладка 1: «Параметры обложки»**
  - Поле ввода учебного года с автодополнением и историей.
  - Интерактивный предпросмотр листа А4 в реальном времени с отступом 30 мм слева под скоросшиватель.
  - Настраиваемый интерактивный разделитель между панелью ввода и предпросмотром.

- **Вкладка 2: «Титульный лист» (стр. 1 журнала)**
  - Вверху: Название организации (по умолчанию: `ГБУ ДО Республиканский детский образовательный технопарк`) с сохранением в историю.
  - В середине: Учебный год (`на гггг/гггг учебный год`).
  - Внизу: Сроки ведения журнала (`Начат «  » месяц 20гг г.`, `Окончен «  » месяц 20гг г.`).
  - Интерактивный предпросмотр листа А4 с отступом 30 мм слева.

- **Вкладка 3: «Оборот титульного листа» (стр. 2 журнала)**
  - Поле ввода Ф. И. О. педагога с сохранением в историю.
  - Интерактивный разделитель между панелью настроек и окном предпросмотра.
  - Предпросмотр листа с правилами ведения (10 пунктов) и отступом 30 мм СПРАВА (под корешок книги).

- **Вкладка 4: «Формирование Excel» (всегда последняя)**
  - Сводка параметров всех страниц журнала.
  - Экспорт любого листа по отдельности:
    - Обложка (внешняя)
    - Титульный лист (стр. 1)
    - Оборот титульного листа (стр. 2)
  - Экспорт полного комплекта (все 3 листа в одной книге Excel).
  - Быстрое открытие созданных файлов в системе.

---

## 🚀 Быстрый запуск

### Вариант 1: Windows (в 1 клик)
Дважды щелкните по файлу `run.bat`. Скрипт автоматически проверит библиотеку `openpyxl` и запустит графический интерфейс.

### Вариант 2: Запуск через терминал (Windows / macOS / Linux)

1. Установите зависимость `openpyxl`:
   ```bash
   pip install openpyxl
   ```
2. Запустите приложение:
   ```bash
   python app_gui.py
   ```
   *(или `python3 app_gui.py` на macOS/Linux)*

## 📁 Структура файлов
- `app_gui.py` — Главный скрипт графического интерфейса Tkinter.
- `journal_generator.py` — Модуль генерации таблиц Excel (`openpyxl`).
- `config.json` — Файл конфигурации и истории ранее введённых данных.
- `run.bat` — Скрипт запуска для Windows.
- `run.sh` — Скрипт запуска для Linux / macOS.
- `requirements.txt` — Список зависимостей Python.
